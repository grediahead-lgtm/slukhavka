# Слухавка

Сторінка послуги для малого бізнесу: голосовий помічник бере слухавку, коли ви зайняті, і пише вам у Telegram; заявки з сайту отримують відповідь за 1–2 секунди.

- `index.html` — сторінка, ціни, форма заявки.
- `privacy.html` — політика конфіденційності.
- `demo-zayavka.mp4`, `demo-poster.jpg` — відео-демо форми заявки.
